About Platform

Skill Exchange Platform is a university-based peer learning system where students can teach skills they know and learn skills they need. Faculty can monitor sessions and approve learning activities to ensure quality knowledge sharing. The platform encourages collaborative learning beyond classrooms using smart matching and real-time session integration.

Key Features

🎓 Skill Sharing

Students teach and learn skills from peers easily.

🤝 Smart Matching

Automatically connects students based on skills.

👨‍🏫 Faculty Monitoring

Faculty approves and monitors sessions.

📅 Session Booking

Book learning sessions with matched peers.

🎥 Zoom Integration

Auto meeting links for real-time learning.

🏆 Gamified Learning

Encourages consistent participation.
